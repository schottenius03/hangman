# 🕹️ Hangman

**Project Overview:** A desktop application delivering a graphical word guessing game constructed with object oriented architecture.  
**Tech Stack:** C++, GUI Framework

## 📌 Overview

Hangman is a native desktop application that demonstrates robust object oriented design patterns and software development principles. Built entirely in C++, the application features a visual user interface that handles real time player interactions, tracks game state progression, and dynamically renders the visual status of the game session.

## Core Architecture

* **Object Oriented Design:** Clean separation of concerns using distinct classes to manage game logic, word banks, and user sessions.
* **Graphical Interface:** A dedicated visual layout that tracks player inputs and displays hidden word progress dynamically.
* **State Management:** Reliable backend logic in C++ to determine victory conditions, score tracking, and remaining attempts.
